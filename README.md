# Flume Frenzy.io

Corrida 3D de tobogã num parque aquático contra bichinhos rivais (bots locais). Arraste para os lados, saia por fora
das curvas para voar e pegar atalhos, empurre os rivais e chegue primeiro na piscina. Três parques (Ilha Tropical,
Vale dos Doces, Pico Gelado), coleção de 18 bichinhos e 9 boias, presente do dia.

- Design: `docs/GDD.md`. Arte: `docs/autoria.md`. Orientação de código: `CLAUDE.md`.
- Feito com o kit multiportal do estúdio (`../distribuicao/kit/README.md`): Poki, CrazyGames (Full e Basic), Y8 e
  californiagames.io a partir do mesmo código.

```bash
npm run servir      # http://127.0.0.1:5500/
npm test
npm run empacotar && npm run verificar
```
